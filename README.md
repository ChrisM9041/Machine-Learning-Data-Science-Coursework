# Machine Learning & Data Science Coursework

A collection of Python notebooks completed as part of machine learning and data science coursework. These exercises provide hands-on experience with data exploration, machine learning models, model validation, and evaluating model performance.

**Note:** The notebooks follow structured course instructions and exercises rather than representing independent projects.

## Technologies & Libraries

- **Python** – Programming language
- **NumPy** – Numerical computing
- **Pandas** – Data manipulation and analysis
- **Matplotlib** – Data visualization
- **scikit-learn** – Machine learning models and evaluation

## Coursework

The repository contains the following notebooks:

| Notebook | Topics Covered |
|---|---|
| `Day5_CompSci.ipynb` | Computer science coursework |
| `exercise1_explore_your_data_1.ipynb` | Data exploration and analysis |
| `exercise2_your_first_machine_learning_model.ipynb` | Building and using a machine learning model |
| `exercise3_model_validation_(1).ipynb` | Model validation |
| `exercise4_underfitting_and_overfitting.ipynb` | Underfitting and overfitting |
| `exercise5_random_forests.ipynb` | Random forest models |

## Learning Objectives

Through these exercises, I gained experience with:

- Exploring and analyzing datasets using Python.
- Preparing data for machine learning.
- Building machine learning models with scikit-learn.
- Evaluating model performance through validation.
- Understanding underfitting, overfitting, and model generalization.
- Applying random forest algorithms.
